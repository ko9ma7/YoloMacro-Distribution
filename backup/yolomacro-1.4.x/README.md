# YoloMacro 1.4.x archive

This folder preserves the legacy YoloMacro documents and screenshots that previously occupied the Distribution root.

- `root/`: former root release notes, notices, and README files
- `docs/`: legacy feature, operation, release, and verification documents
- `artifacts/`: legacy UI screenshots

No source migration or OpenCV 5 development occurs here. The unchanged source history remains in `ko9ma7/YoloMacro`, and released binaries remain attached to the existing `v1.*` GitHub Releases.

Current VisionFlow Studio material belongs at the Distribution root and in `docs/`.
