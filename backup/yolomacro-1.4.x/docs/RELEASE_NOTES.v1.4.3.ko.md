# YoloMacro v1.4.3 릴리즈 노트

배포일: 2026-07-28

## OCR 액션

- 한국어·영문·숫자를 읽는 Tesseract OCR과 재사용 프로필을 추가했습니다.
- 읽기 성공, 포함, 전체 일치, 정규식, 숫자 이상/이하 판정을 지원합니다.
- 텍스트·숫자·신뢰도와 정규식 이름 그룹을 결과 변수로 후속 키 입력·메시지·분기에 전달합니다.
- ROI 즉시 테스트, 전처리, 확대, 반전, 허용 문자, PSM, 최소 신뢰도 설정을 제공합니다.

## 대표 이미지 사전

- 대상 창 또는 카메라의 ROI를 `ready/busy/error` 같은 라벨별 샘플로 저장합니다.
- 특정 라벨 탐색 또는 전체 라벨 분류, 색상/회색/윤곽 비교와 다중 크기 허용을 지원합니다.
- 기존 클릭·키 입력·분기·Replay·능동 학습 흐름과 함께 사용합니다.

## 설치 주의

v1.4.3에는 Tesseract 관리 DLL, x64/x86 네이티브 런타임과 한국어·영문 언어 데이터가 들어 있습니다. 기존 설치의 `YoloMacro.CoreLib.dll` 하나만 교체하면 안 됩니다. 전체 `YoloMacro-v1.4.3-win-x64.zip`을 새 폴더에 풀어 실행하세요.

자세한 설정은 [OCR·대표 이미지 사전 가이드](OCR_AND_VISUAL_DICTIONARY_GUIDE.md)를 참고하세요.
