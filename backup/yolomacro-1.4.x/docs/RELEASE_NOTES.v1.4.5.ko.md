# YoloMacro v1.4.5 릴리즈 노트

## 동일 대상 추적

- `마우스 액션`과 `찾은 동일 대상을 계속 따라가기`를 분리했습니다.
- 클릭·키 입력은 최초 인식 시 기존 설정대로 한 번 실행하고, 이후에는 커서만 대상 중심을 따라갑니다.
- 광학 흐름, 최초·중간 외형 샘플 재탐지와 최근 속도 예측으로 이동·회전·밝기 변화·점진 투명화를 추적합니다.
- 대상이 잠깐 가려지면 설정한 유실 허용 프레임 동안만 이동을 예측하며, 한도를 넘으면 다른 대상으로 바뀌지 않도록 종료합니다.

## YOLO 하이브리드

- YOLO는 필수가 아닙니다. 연속적인 모습 변화는 기본 시각 동일성 추적으로 사용할 수 있습니다.
- 큰 외형 변화나 가림 뒤 재등장은 `시각 + YOLO 하이브리드`를 선택할 수 있습니다.
- 같은 클래스 후보가 여러 개면 이전 위치·속도·겹침을 함께 비교해 동일 개체를 재결합합니다.
- YOLO 모델이 없으면 시각 동일성 방식으로 안전하게 대체됩니다.

## 호환성과 검증

- 기존 `대상 따라가기` 프로젝트는 새 독립 추적 설정으로 자동 변환됩니다.
- 이동·회전·점진 투명화, 잠깐의 완전 가림과 같은 클래스의 먼 방해 대상을 합성 회귀 검사로 검증했습니다.
- Release 빌드, 보안·업데이트 11개 시나리오, 전체 워크플로 회귀와 WPF 설정 화면 검증을 통과했습니다.
- OCR과 네이티브 비전 런타임이 포함되므로 단일 DLL이 아니라 전체 ZIP을 새 폴더에 풀어 사용하세요.

자세한 사용법은 [동일 대상 추적 가이드](TARGET_IDENTITY_TRACKING_GUIDE.md)를 참고하세요.
