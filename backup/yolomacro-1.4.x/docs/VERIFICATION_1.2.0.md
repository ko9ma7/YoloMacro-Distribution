# YoloMacro 1.2.0 검증 기록

검증일: 2026-07-11

## 회귀 원인과 검증

1. **이미지 검색 무한 반복**
   - 가설: 임계값이 0일 때 이미 제거된 후보의 점수가 0으로 남아 반복 검색이 끝나지 않는다.
   - 재현: 임계값 자동 보정 회귀 테스트가 이미지 검색에서 시간 초과됐다.
   - 조치: 점수가 0보다 큰 후보만 다음 결과로 인정하도록 종료 조건을 보강했다.
   - 결과: 임계값 자동 보정과 전체 워크플로 회귀 테스트가 통과했다.

2. **관찰 실행의 실제 입력 차단**
   - 가설: 관찰 실행에서도 캡처는 수행하되 마우스, 키보드, 웹훅, AI 전송은 실행되면 안 된다.
   - 검증: 가짜 런타임 어댑터로 캡처 횟수와 실제 액션 횟수를 분리 측정했다.
   - 결과: 캡처는 수행되고 실제 액션 횟수는 0인 것을 확인했다.

3. **업데이트 패키지 변조와 경로 이탈**
   - 가설: ZIP 내부의 `../` 경로가 설치 폴더 밖에 파일을 만들 수 있다.
   - 검증: 정상 ZIP과 경로 이탈 ZIP을 각각 추출했다.
   - 결과: 정상 ZIP만 허용되고 경로 이탈 ZIP은 거부됐다. 실패하도록 만든 적용 스크립트를 실제 실행해 기존 파일 복원과 새 파일 제거를 확인했다.

## 자동 검증

- Release 잠금 복원 및 빌드
- 워크플로 회귀 스모크 테스트
- 액션 설정 및 반응형 UI 스모크 테스트
- NuGet 알려진 취약점 감사
- GitHub Actions 빌드, CodeQL, 비밀정보 검사, CycloneDX SBOM, 릴리스 해시 생성 구성

유료 인증 서비스는 사용하지 않는다. GitHub의 무료 Actions, CodeQL, Dependabot, artifact attestation과 SHA-256 검증을 사용한다. 유료 코드 서명 인증서가 없으므로 Windows SmartScreen 경고를 완전히 제거할 수는 없다.
