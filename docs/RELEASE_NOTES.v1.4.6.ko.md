# YoloMacro 1.4.6 릴리즈 노트

- ROI 전체를 배경으로 학습한 뒤 새로 나타난 연결 도형을 별도 캡처 이미지 없이 추적합니다.
- 실제 도형 윤곽을 표시하고 작은 `+` 포인터·커서 변화는 최소 면적으로 제외합니다.
- 대상이 이동하다 멈추거나 사라지면 마지막 확정 중심을 클릭하고 작업 목록으로 돌아갑니다.
- 관찰 실행에서도 클릭 없이 동일한 윤곽·상태 전이를 실시간으로 확인할 수 있습니다.
- 키 누름 시간, 반복 횟수, 반복 간격을 각각 설정합니다.
- 두 제품의 활성화 정책·공개키를 한 정책 파일로 관리하면서 제품별 서명문을 분리했습니다.
- 매주 자동 재서명해 수동 날짜 관리로 배포가 만료되는 문제를 방지합니다.
