# 동일 대상 추적 가이드

YoloMacro 1.4.5의 추적은 “같은 템플릿을 다시 찾는 기능”과 다릅니다. 이미지를 한 번 찾아 추적 ID를 만든 뒤, 대상의 이동·회전·밝기 변화·점진 투명화를 연속 프레임에서 따라갑니다.

## 클릭과 추적의 관계

`마우스 액션`과 `찾은 동일 대상을 계속 따라가기`는 별도 설정입니다.

1. 최초 탐색에 성공합니다.
2. 선택한 마우스 액션과 키 입력을 한 번 실행합니다.
   - 클릭하지 않으려면 `마우스 동작 안 함`을 선택합니다.
   - 한 번 클릭하려면 `좌클릭`을 선택합니다.
3. 추적이 켜져 있으면 이후 프레임에서는 커서만 대상 중심을 따라갑니다.
4. 대상이 허용 프레임보다 오래 사라지거나 최대 시간이 끝나면 추적을 종료합니다.

기존 프로젝트의 `대상 따라가기` 마우스 액션은 불러올 때 `마우스 동작 안 함 + 동일 대상 추적 켜짐`으로 자동 변환됩니다.

## 추적 방식

| 방식 | 동작 | 권장 상황 |
|---|---|---|
| 시각 동일성 | 광학 흐름으로 연속 이동을 계산하고, 최초 모습과 신뢰도 높은 중간 모습을 이용해 지역 재탐지 | 이미지로 시작할 수 있고 모습이 점진적으로 변하는 대상 |
| 시각 + YOLO 하이브리드 | 시각 동일성 추적에 같은 YOLO 클래스의 주기적 재탐지를 추가하고, 이전 위치·속도·겹침으로 동일 개체를 연결 | 외형 변화가 크거나 잠깐 가려지고 같은 종류의 물체가 여럿 나오는 화면 |

YOLO는 항상 필요한 것이 아닙니다. 첨부 영상처럼 사각형이 연속적으로 이동·회전·투명해지는 동안에는 시각 동일성 추적이 중심 이동을 유지할 수 있습니다. 갑자기 완전히 다른 모습으로 바뀌거나 가림 뒤 다른 위치에서 다시 나타나는 경우에는 변화 단계까지 학습한 YOLO 하이브리드가 더 안정적입니다.

## 투명화의 물리적 한계

대상이 희미해져도 주변과 구분되는 모서리·질감·명암이 남아 있으면 추적할 수 있습니다. 완전히 투명해져 화면 픽셀이 배경과 같아지면 OpenCV와 YOLO 모두 직접 관측할 정보가 없습니다. YoloMacro는 이 짧은 구간에서 최근 속도로 위치를 예측하지만, `이탈 허용 프레임`을 넘으면 잘못된 대상을 따라가지 않도록 종료합니다.

## 권장 설정

1. 대상 전체와 내부 특징이 포함되도록 시작 이미지를 캡처합니다.
2. `마우스 액션`에서 최초 1회 동작을 선택합니다.
3. `찾은 동일 대상을 계속 따라가기`를 켭니다.
4. 일반적인 시작값은 다음과 같습니다.
   - 간격: `33ms`
   - 최대 시간: `0` (무제한)
   - 이탈 허용: `8프레임`
   - 재탐색 반경: `120px`
   - YOLO 재탐지: `250ms`
5. 빠르게 움직이면 반경을 늘리고, 비슷한 물체로 잘못 이동하면 반경과 이탈 허용을 줄입니다.
6. 하이브리드에서는 YOLO 모델을 먼저 로드하고 대상 클래스명을 정확히 지정합니다.

## YOLO 학습 데이터 준비

한 클래스가 한 대상의 여러 모습이라는 의미가 되도록 다음 장면을 같은 클래스에 포함합니다.

- 정면·회전·크기 변화
- 밝음·어두움·반투명 단계
- 일부 가림과 모션 블러
- 실제 배경 종류
- 대상이 없는 negative 이미지

완전 투명한 프레임에는 보이지 않는 상자를 억지로 라벨링하지 않습니다. 그 구간은 관측이 아니라 짧은 이동 예측으로 처리합니다.

## 내장 템플릿

- `기본 탐색 → 변하는 대상을 커서로 계속 추적`
- `YOLO → YOLO 동일 대상 하이브리드 추적`

템플릿을 추가한 뒤 이미지·ROI·클래스명·마우스 액션만 실제 화면에 맞게 바꾸면 됩니다.

## 검증

1. `관찰 실행`에서 최초 대상과 분기를 확인합니다.
2. 실제 입력 전에 마우스 액션을 `동작 안 함`으로 두고 커서 이동만 시험합니다.
3. 회전, 투명화, 잠깐 가림, 같은 클래스의 방해 대상을 포함해 시험합니다.
4. 실행 로그의 `광학 흐름`, `외형 재탐지`, `YOLO 재탐지`, `대상 재획득`을 확인합니다.
