# VisionFlow Studio 2.7.0

## 자연스러운 실제 마우스 이동

- 기존 클릭 위치 랜덤화와 이동 경로 랜덤화를 분리했습니다.
- 실제 커서와 Interception 이동은 거리 기반 Waypoint, 상관 난수, Catmull-Rom 곡선으로 전체 경로를 먼저 생성합니다.
- 출발 가속, 순항, 감속, 마지막 정밀 접근의 속도 프로파일을 이동마다 제한적으로 바꿉니다.
- 짧은 이동은 거의 직선으로 유지하고 긴 이동도 최대 이탈 범위를 넘지 않습니다.
- 선택 옵션인 Overshoot는 긴 이동과 충분한 안전 영역에서만 낮은 확률로 적용됩니다.

## 클릭 정확도와 호환성

- 탐지 Bounding Box 외곽을 제외한 Safe Click Zone 안에서 기존 랜덤 목표 좌표를 제한합니다.
- 마지막 이동점은 목표 좌표와 정확히 일치하며 미세 보정 옵션으로 실제 커서 위치를 다시 확인합니다.
- 비활성 PostMessage에는 경로 생성을 강제하지 않습니다.
- 기존 프로젝트와 액션은 기본 `즉시 이동`으로 불러와 2.6.0 이하 동작을 유지합니다.
- 전체 설정, Compact 설정, 다중 선택 복사와 일괄 변경, 프로젝트 JSON 저장/불러오기를 지원합니다.

## 실행 안정성

- 액션 추가 직후 실행 검사가 이전 내부 목록을 사용해 이미 삭제되거나 이름이 바뀐 액션을 검사하던 문제를 수정했습니다.
- 실행 버튼은 화면에 표시된 최신 액션 트리를 평탄화한 동일 목록으로 안전 검사와 실행을 수행합니다.

## 기반 업데이트

- OpenCvSharp/OpenCV 5.0.0.20260806 기반 Windows x64 전환 결과를 정식 배포에 포함합니다.
- OpenCV, YOLO, AOI, OCR 등 기존 탐지 엔진과 마우스 경로 생성 모듈은 서로 독립적으로 유지됩니다.

## 검증

- Release 빌드, 보안 검사, 추적 회귀 검사와 자연 경로 전용 회귀 검사를 통과합니다.
- 경로 마지막 좌표, 최대 이탈, 진행 방향, Safe Click Zone, 이동별 경로 차이와 이전 JSON 호환을 자동 검사합니다.
