# VisionFlow Studio Distribution

**VisionFlow Studio 2.6.0** is the current product. **YoloMacro 1.4.6** is maintained as a legacy release.

- [Download VisionFlow Studio 2.6.0](https://github.com/ko9ma7/YoloMacro-Distribution/releases/tag/v2.6.0)
- [VisionFlow Studio 2.6.0 release notes](docs/VISIONFLOW_STUDIO_2.6.0.md)
- [Download legacy YoloMacro 1.4.6](https://github.com/ko9ma7/YoloMacro-Distribution/releases/tag/v1.4.6)
- [Unified web activation operations](docs/UNIFIED_WEB_ACTIVATION.md)

Both products use separate schema 3 product IDs and channels under the same web-managed signing authority. Policies do not expire automatically; only a channel rotation or explicit disable invalidates an installed build.
